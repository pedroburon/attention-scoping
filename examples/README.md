# Examples

Each subdirectory contains an `.attention.yml` for a representative project
shape. Copy the closest one to your repo root and adjust the paths.

| Example                              | Shape                                          |
|--------------------------------------|------------------------------------------------|
| [`monorepo/`](monorepo)              | Multi-package monorepo (apps + shared libs)    |
| [`django-react/`](django-react)      | Django backend + React frontend in one repo    |
| [`microservices/`](microservices)    | Several services with a shared `proto/` and lib|

These are templates, not opinions. The paths are illustrative — your repo's
layout will differ. The shape of the scope choices (by feature, by surface,
by service) is the part worth copying.
